# Initial Plan

- Model: GPT-5.4
- Harness: Codex
- Reasoning: Extra High

The team's initial plan is to do a bit of a baton pass. Each pair focused on one research topic, so the responsibility is on that pair to get those features implemented in however many entries it takes before passing the baton to the next pair (goal should be 4+ entries per pair). The pair will commit that version of the slot machine to the repository and document relevant information (code/app quality). In order to avoid overcomplicating things, the team won't be using skill files (*this is subject to change depending on how effective/ineffective the prompts are*). Due to the relatively low amount of prompts each member needs to do, Extra High reasoning will be used to optimize Codex's effectiveness per entry. This is also subject to being lowered if the plan changes significantly and/or tokens are low.
