How Wins Are Paid

Horizontal paylines award for 3, 4, or 5 matching adjacent symbols. Vertical and diagonal paylines contain three positions, so they award only on 3 of a kind. If multiple paylines qualify on the same spin, only the highest-paying payline is credited.

Location Reminder

The game requests device location or a manually selected state before play because gaming requirements differ by state. This reminder is stored locally only and does not verify legal eligibility.
